This respository corresponds to the paper "Performance of Quantile Regression Methods with Discrete Outcomes: A Simulation Study with Applications to Environmental Epidemiology", citation TBA.

This repository contains all code used to run, clean, and create tables/ figures for the simulation study. It also contains the raw and cleaned simulation study results. 

IMPORTANT NOTE: Users must unzip the raw simulation results (QR-with-discrete-outcomes/data/raw/QR sim study_all models_2025-09-08_1000_sims.rar), as the original file is too large to be uploaded to github.

This repositiory also contains the code used to run the analysis with the Maternal-Infant Research on Environmental Chemicals (MIREC) study. Note that the underlying MIREC data cannot be made publically available due to privacy converns. Researchers may apply to access the data through the MIREC biobank (https://www.mirec-canada.ca/en/research/).

Corresponding author: Joshua D. Alampi (jalampi@sfu.ca).
